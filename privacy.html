Privacy & limits The short version: your documents never leave this device — and here's exactly how far this little app can be pushed.

Privacy

No server. No account. No analytics. No cookies. Staple is one static HTML file. There is no backend, no database, and no upload endpoint — so it cannot send your documents anywhere, by design and by architecture.

What happens to your files: read by the browser's File APIs, kept in your browser's IndexedDB (staple-db), merged in your tab's memory, written straight to a download. All local. Nothing is uploaded, ever.

The only network requests: four pinned library files from cdnjs.cloudflare.com (pdf-lib, pdf.js + its worker, JSZip) and one font from Google Fonts — loaded once, then served from your browser's cache. Those CDNs see an IP address making a request; they never see a byte of your paperwork. Two conditional exceptions, same CDN, same rule: drop an iPhone photo (HEIC) and the browser fetches a pinned decoder (heic2any); drop a spreadsheet (.xlsx) and it fetches a pinned reader (SheetJS). Each loads once, then caches. Your file is processed locally either way.

The browser refuses to leak. The app ships a strict Content-Security-Policy with connect-src 'none' — no fetch, XHR or WebSocket to anywhere can succeed, even if the code tried. The test suite fails if any request ever goes beyond the pinned files above. Full fine print: script sources are pinned to this file and cdnjs, and the policy carries one allowance, unsafe-eval, because the HEIC decoder's WASM glue needs it — connections stay forbidden either way, so even eval'd code cannot send a byte anywhere.

It works offline. After the first visit a network-first service worker answers from its cache only when the network fails; online behaviour is identical to a browser without it, and it never sends anything.

Where your data lives: IndexedDB database staple-db (files, order, copies, removals) and two localStorage keys (staple-theme, staple-fname). That's the complete list.

Verify it yourself: open DevTools → Network and drop a document in — no request contains your file. Check Application → IndexedDB — your pile is sitting there, locally. Or read the code: the site you're using is the code in the public repository, line for line.

Leave any time: the Clear browser storage button wipes IndexedDB and localStorage completely. There's no copy kept behind, because there's nowhere to keep one.

How much can Staple handle?

Staple runs entirely on your device, so its ceiling is your device's ceiling. The honest numbers:

DimensionLimitThe fine print
Copies per file99Hard cap, by design. If the embassy wants more than 99, the embassy is being unreasonable.
Pages in the merged PDFNo hard capThousands of pages work; every page gets its own preview card, so very large piles make the page itself heavier. A few hundred pages is the comfort zone.
File typesPDF, JPG, PNG, WebP, GIF, BMP, AVIF, HEIC, TXT, MD, CSV, XLSXImages become one A4 page each; text files become selectable text pages (standard fonts, Latin scripts — exotic characters render as ?); each spreadsheet sheet becomes a titled page of aligned cell values. Owner-locked PDFs are flattened to images; password-protected PDFs are skipped. Word docs, legacy .xls, TIFF? The app tells you to export or convert first — out loud, never silently.
OfflineWorks after the first visitInstallable on phones. A network-first service worker answers from its cache only when the network fails; the typeface may fall back to a system font offline.
Storage (the pile)Browser quotaFiles are kept in IndexedDB. Chrome lets a site use roughly 60% of free disk; Safari is stingier. The meter at the bottom of the pile shows live usage. If storage fills up, new files last only until the tab closes — a toast warns you.
Memory (the merge)Your tab's RAMSource files plus the merged PDF live in memory while you work. A pile of a few hundred MB is comfortable on a laptop; a single 500 MB scan will test both your patience and your cooling fan.
Locked PDFsOutput growsEncrypted pages are re-encoded as images at 2.2× zoom, so merged output gets chunkier than the source.
DevicesOne browserNo sync, no share links. The pile lives in this browser on this machine — browser storage is a desk, not a filing cabinet. Keep your originals.
