Waiting for links.
This is the one page that talks to other hosts — it fetches only the https links you paste, so those hosts see your IP the way any download would. The documents themselves land in the same browser-only IndexedDB as dropped files and never leave your device. The main app keeps its stricter no-outbound-connections policy. A host that refuses browser downloads (CORS) will be told on: save the file and drop it instead.
